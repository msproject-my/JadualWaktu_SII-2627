Tetapan Google Sheets (Mod Pentadbir)

Masukkan pautan Publish to web (format CSV) daripada Google Sheet agihan. Semua pensyarah yang membuka portal akan melihat data terkini ini secara paparan sahaja.

Cara dapatkan link CSV dari Google Sheets anda:
1. Buka Google Sheet agihan jadual anda.
2. Klik File > Share > Publish to web.
3. Pilih Sheet/Helaian berkenaan, ubah Web page kepada Comma-separated values (.csv).
4. Klik Publish dan salin pautan URL tersebut ke kotak di bawah.
